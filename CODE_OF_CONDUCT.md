# Code of Conduct

## Expected Behavior

- Discuss code, evidence, and tradeoffs without attacking people.
- Give reproducible examples and redact credentials, private URLs, and page
  content.
- Respect browser owners, website terms, authentication boundaries, and local
  law.
- Report security-sensitive material privately through [SECURITY.md](SECURITY.md).

## Unacceptable Behavior

- Harassment, threats, discrimination, or sustained disruption.
- Publishing another person's secrets or private data.
- Pressuring contributors to add CAPTCHA bypasses, credential theft, evasive
  automation, or destructive browser actions.
- Misrepresenting an unverified proposal as a completed or verified browser
  action.

## Scope and Enforcement

This policy applies to project repositories, issues, reviews, discussions, and
other project spaces. Maintainers may edit or remove content, close
conversations, reject contributions, or restrict participation when behavior
violates this policy.

Report conduct concerns privately to the maintainer through their GitHub
profile. Good-faith reports will be reviewed with discretion. Retaliation is
not permitted.

This policy is informed by the Contributor Covenant, version 2.1.
